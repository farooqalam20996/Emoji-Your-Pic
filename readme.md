# Emoji Your Pic

**Emoji Your Pic** is a mobile application that allows users to transform their images into personalized emojis and share them seamlessly. The app integrates messaging, profile management, and AI-based image conversion into one user-friendly platform.

This project demonstrates full-stack mobile app development skills, including authentication, real-time communication, AI integration, and media processing.

---

## Overview

Emoji Your Pic enables users to:

* Communicate with friends via real-time chat.
* Access call logs and frequently contacted users.
* Create expressive emoji avatars from their own images.
* Manage profiles and user activity efficiently.

The app showcases a complete mobile development workflow, from frontend interface to backend services and AI-powered image processing.

---

## Key Features

### Authentication

* Login and signup with email or phone number.
* Secure OAuth 2.0 authentication.
* Forgot password flow for account recovery.

### Messaging & Communication

* Real-time chat functionality with friends.
* View call logs and frequently contacted users.
* Profile management for user activity tracking.

### AI Image-to-Emoji Conversion

* Convert uploaded images into personalized emojis.
* Share generated emoji avatars directly with friends.

### Profile Management

* Edit user information.
* View user profile activity and updates.

---

## Tech Stack

* **Frontend:** React Native
* **Backend:** Firebase / Node.js / REST API
* **Database:** Firestore / MongoDB
* **Authentication:** Firebase Auth with OAuth 2.0
* **AI Integration:** Image-to-Emoji conversion

## Installation

To run the app locally, follow these steps:

```bash
git clone https://github.com/farooqalam20996/EmojiYourPic.git
cd EmojiYourPic
npm install
npx react-native run-android
```

Ensure you have React Native and Android Studio configured correctly.
